## 已确认

### 产品定位与名称

RepoDesk 是面向 Windows 的多仓库 Git 管理控制台，集中查看和操作多个本地 Git 仓库。RepoDesk 为正式产品名称。

### 页面入口

主导航为总览、全部项目、项目操作、操作记录和设置。项目操作页面向当前选中的仓库。

### 仓库扫描

- 仓库根目录由用户在设置页选择。
- 默认最大扫描深度为两层，用户可调整深度。
- 扫描跳过常见依赖与构建目录。

### Git 操作安全原则

- Fetch 用于更新远程引用，不会拉取或改动工作区。
- 批量更新遇到未提交修改、分叉或冲突风险时应跳过并说明。
- 不静默覆盖或重置用户内容。
- 断网或远程失败时显示失败原因。

## 已实现的应用约定

- 当前开发版本为 0.2.0。
- 总览和全部项目页面提供批量拉取、批量推送；仅对远程差异明确且安全的仓库执行，并汇总跳过/失败项。

- 桌面框架使用 Electron、React、TypeScript、Vite 和 Tailwind CSS。
- 窗口使用自定义标题栏控件；渲染进程通过 preload 的受限接口控制窗口。
- 点击刷新会对发现的仓库执行 `git fetch --prune`，最多并发 3 个仓库，然后计算当前分支与 upstream 的 ahead/behind。
- 项目详情展示本地文件状态和最近五条提交记录。
- 项目操作支持查看文件差异、逐项或批量暂存/取消暂存，以及提交已暂存文件；提交与推送结果写入操作历史。
- Push 前 Fetch 并检查 upstream；仅在本地领先且远程未领先时允许推送。

### 快捷操作与记录

- 项目列表的刷新按钮只 Fetch 当前仓库；批量刷新仍使用页面顶部的全局刷新。
- Fetch、Pull、Push 结果保存在本机操作历史中，最多保留 500 条。
- Pull 使用 `--ff-only`，工作区有改动或分支分叉时拒绝执行；Push 前 Fetch 并检查远程是否领先。
- 总览按最近提交时间倒序，并在末尾单独展示收藏项目。
- 每个项目的备忘以仓库路径为键保存在应用本机设置中。

### 项目备忘

设置页可选择将项目备忘保存在本机，或写入每个仓库根目录的 `list.md`。切换存储方式时，会将当前扫描到的仓库备忘迁移到新位置；写 `list.md` 时只更新 RepoDesk 标记区，保留其余内容。

### 冻结远程更新检查

项目行上的暂停按钮可冻结/恢复该项目的远程 Fetch。冻结时仍扫描本地 Git 状态，但跳过远程 Fetch，并禁用该项目的 Pull/Push；恢复后远程状态显示“等待远程检查”，直到下一次 Fetch。



### 通用文档库

- Markdown 通用文档可在本机 RepoDesk 文档库中创建或导入，并发布到一个或多个仓库的相对路径。
- 发布前检测目标文件；内容不同时先提示，用户确认后才覆盖。
- 发布结果写入操作历史；删除文档库条目不删除已发布到仓库中的文件。
